## bifurcado experimental del proyecto wren.

Este repositorio busca servir de base de prueba, para la realización de experimentos y pruebas de ideas sobre el fantástico proyecto de wren, por lo que este proyecto en particular no está orientado a una versión estable del todo sino más bien a estudio y experimentación si desea probar el proyecto base, puede ir al repositorio principal del proyecto: https://github.com/wren-lang/wren
